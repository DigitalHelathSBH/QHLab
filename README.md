# หน้าเว็บปริ้นบัตรคิว ห้องจ่ายยา OPD

ค้นหาคิวห้องจ่ายยา OPD ของผู้ป่วยจากเลข HN (เฉพาะคิวของวันปัจจุบัน) แล้วปริ้นบัตรคิว
ลงกระดาษครึ่ง A4 ด้วยเครื่องปริ้นทั่วไป

## ติดตั้ง

```
npm install
copy .env.example .env
```

แก้ค่าใน `.env` ให้ตรงกับเซิร์ฟเวอร์ SQL Server จริงของ รพ. (server, database, user/password
หรือ Windows Authentication) และชื่อโรงพยาบาลที่จะแสดงบนบัตร

## สิ่งที่ต้องตรวจสอบก่อนใช้งานจริง (สำคัญ)

ชื่อคอลัมน์ในไฟล์ [`src/config/fieldMap.js`](src/config/fieldMap.js) เป็นการเดาจากตัวอย่างบัตรคิวที่ได้รับมา
เนื่องจากยังไม่มีสคีมาจริงของตาราง `ssbdatabase.dbo.QuickWin_PharOPD` กรุณา:

1. รันคำสั่ง `SELECT TOP 1 * FROM ssbdatabase.dbo.QuickWin_PharOPD` เพื่อดูชื่อคอลัมน์จริง
2. แก้ค่าฝั่งขวาของแต่ละบรรทัดใน `fieldMap.js` ให้ตรงกับชื่อคอลัมน์จริง (ไม่ต้องแก้โค้ดไฟล์อื่น)

ถ้าต้องการ URL ให้ผู้ป่วยตรวจสอบสถานะคิวผ่าน QR Code แทนที่จะเข้ารหัสแค่หมายเลขคิวเฉยๆ
ให้ตั้งค่า `QUEUE_STATUS_URL_TEMPLATE` ใน `.env` โดยใช้ `{QUEUE}` แทนตำแหน่งหมายเลขคิว เช่น
`https://queue.example-hospital.go.th/status?q={QUEUE}`

## รัน

```
npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` กรอกเลข HN แล้วกด "ค้นหา / ปริ้นบัตรคิว"
ระบบจะค้นหาเฉพาะคิวของ HN นั้นในวันปัจจุบันเท่านั้น (ล็อกวันที่อัตโนมัติ ไม่ต้องเลือกวันที่)

## ขนาดกระดาษที่พิมพ์

ค่าเริ่มต้นตั้งไว้ที่ 105mm x 297mm (นำกระดาษ A4 มาตัดครึ่งตามแนวยาว) กำหนดไว้ที่ตัวแปร
`--ticket-width` / `--ticket-height` ในไฟล์ [`src/public/css/ticket.css`](src/public/css/ticket.css)
หากต้องการขนาดอื่น (เช่น A5 แนวตั้ง 148mm x 210mm) แก้ค่าตรงนี้ได้เลย แล้วตั้งขนาดกระดาษเดียวกัน
ในหน้าต่างสั่งพิมพ์ของเบราว์เซอร์ (Print > More settings > Paper size > Custom)

## โครงสร้างโปรเจกต์

```
src/
  server.js          จุดเริ่มเซิร์ฟเวอร์ Express
  db.js              เชื่อมต่อและคิวรี SQL Server
  config/fieldMap.js ผูกชื่อคอลัมน์จริงในตาราง -> ข้อมูลบนบัตรคิว (แก้ตรงนี้)
  routes/index.js    หน้าค้นหา (/) และหน้าปริ้นบัตรคิว (/print?hn=...)
  views/             เทมเพลต EJS (search.ejs, ticket.ejs)
  public/css/        สไตล์หน้าเว็บและสไตล์สำหรับพิมพ์
```
